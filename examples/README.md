# 效果展示

演示视频待补充。本次首次发布未包含视频文件，本页不将规划示意当成实际生成结果。

## 案例格式

每个案例使用独立目录，例如 `examples/rainwater-explainer/`，并提供：

| 文件 | 内容 |
| --- | --- |
| `README.md` | 案例简介、生成模型与日期、是否经过剪辑、复核说明 |
| `input.md` | 可公开的输入稿件与创作约束 |
| `plan.json` | 与最终 Prompt 对应的导演方案 |
| `prompt.md` | 实际使用的提示词 |
| `preview.jpg` | 从最终视频提取的封面 |
| `demo.mp4` 或视频链接 | 实际效果，不能以参考作品代替 |

这些文件名是后续贡献约定，目前尚未提供对应案例。每条案例还应注明视频、音乐、字体与其他第三方素材的授权，以及是否允许再分发。媒体授权与仓库代码许可需要分别说明。

首页展示优先使用封面链接到可播放视频；较大的视频可以放入 GitHub Release 附件，避免不断扩大 Git 历史。请勿提交失效后无法播放的临时授权链接。
