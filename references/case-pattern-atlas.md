# 去来源化方法家族图谱

本图谱只保存已经被案例“消化”后的可迁移知识。使用时不检索原片题名、案例编号或时间位置，只判断当前稿件需要哪种认知任务、视觉世界、证据责任和状态变化。细粒度调用以 [method-composition-engine.md](method-composition-engine.md)、[method-trigger-lattice.yaml](method-trigger-lattice.yaml)、[director-method-recipes.json](director-method-recipes.json) 和 [director-move-catalog.yaml](director-move-catalog.yaml) 为准。

## 稳定方法家族

| 方法家族 | 适用判断 | 画面骨架 | 必守边界 |
|---|---|---|---|
| 持久工作台/窗口 | 长片、多来源、连续调查 | 外框与核心槽位不动，内容增量更新 | 关键证据可临时全屏，读完必须回槽 |
| 对象身份锁 | 产品、人物、机制、代际 | 同一对象保持位置、尺度、朝向、材质和光源 | 不用不同对象伪装前后变化 |
| 原始材料取证 | 引用、文件、公告、真实 UI | 全貌建立出处，局部框选放大，再回到上下文 | 不重打一行大字冒充原始证据 |
| 题材原生隐喻 | 抽象判断、机制、流程 | 选择与论点同构的空间和物体状态 | 不因“科技感”使用万能芯片、火箭或 HUD |
| 语义色状态机 | 多主体、风险、流向、阶段 | 中立基线先建立，颜色随状态变化出现 | 颜色不能抢先制造尚未成立的结论 |
| 章节清场 | 年代、主体、核心命题发生变化 | 旧状态收束，清场停顿，新章首对象建立 | 普通属性更新不得重启整个视觉世界 |
| 实拍证明/MG 解释 | 产品、现场、采访、真实行为 | 真实素材承担存在，MG承担不可见关系和机制 | 不重画清楚的 UI，不让生成画面冒充现场 |
| 文字职责分层 | 标题、结论、标签、数据、原文 | 不同文字角色分时进入固定槽位 | 不加底部旁白字幕，不让大字重复旁白全文 |
| 单拍单主动作 | 高能包装、流程、性能、解释 | 一个对象完成一个状态变化，反馈晚半拍 | 相机、形变、粒子、文字不能同时争主动作 |
| 因果链回收 | 生态、资金、能源、故障 | 原因、机制、结果逐步成立并保留旧状态 | 结尾回到后果或结论，不在中途清零 |
| 跨媒介共同锚 | 实拍、档案、3D、MG 混合 | 保留对象、地图、时间、形状或动作中的一个锚 | 每换媒介不换一套世界和转场语法 |
| 跨画幅安全容器 | 横竖屏、网页、聊天、旧档案 | 稳定容器吸收比例差异，关键局部按焦点放大 | 不拉伸、不模糊填边、不把来源缩成邮票 |

## 视觉世界家族

### 证据纸面

适合引用、历史、调查、政策和人物材料。以页边、日期、来源、框选和层叠建立可信度。风险是贴纸化、纹理压字、整页缩小后不可读。

### 技术观察台

适合对象结构、内部机制、信号路径和参数变化。以稳定坐标完成总览、剖面、作用路径和回装。风险是泛 HUD、发光过量、随机粒子和解释后忘记回到整体。

### 产品英雄舞台

适合产品能力、规格、发布和使用结果。产品身份始终占第一阅读，机制、参数和文字只进入辅助槽。风险是纯环绕展示、连续大字、图表抢走产品主体。

### 数据与关系工作区

适合比较、榜单、成本、人物关系、产业和生态。先建立单位、基线、节点或关系类型，再增量更新。风险是 PPT 化、数字无口径、关系无方向、地图只发光。

### 领域原生容器

适合建筑、交通、能源、影院、制造等已有强空间语法的题材。让题材对象本身提供容器、转场和连续锚。风险是容器成为装饰，或为了形式挤压真实证据。

## 使用原则

1. 一个 4–15 秒语义段只能有一个持久世界、一个主认知程序和一个关键变化。
2. 方法家族可以组合，但每个叠加方法必须声明自己只承担证据、比较、文字、媒介接力、连续性或结尾中的哪一项责任。
3. 同一方法在不同稿件里必须重新实例化为当前主体、坐标、初态、变化和终态，不能复用案例表面造型。
4. 原片只在研究阶段用于发现和反证；进入 Skill 的知识不保留原片坐标，不要求使用者回看来源。
5. 新观察先拆成原子动作、触发条件和失败边界；稳定后再归入方法家族或复合配方，不能把“看起来不错”直接写成规律。
