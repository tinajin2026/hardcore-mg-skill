## 质量语义

“不低于参考片”不能由 Prompt 文件存在或单次模型调用证明。Skill 只在三层同时成立时标记 `ready`：

1. **策划层**：语义、构图、状态、运动、声音和连续性完整，达到本页分数。
2. **模型层**：H3 模式、时长、画幅、素材角色和原生 Prompt 符合官方合同。
3. **成片层**：实际生成后通过逐帧、声画和跨段复核。

没有生成成片时，输出只能声称“策划与 Prompt ready”，不能声称“成片质量已达标”。

## 100 分评分

| 维度 | 满分 | 可观察条件 |
|---|---:|---|
| semantic_fidelity | 20 | 原稿事实、数字、因果和语气不被改写；核心判断唯一且可见 |
| visual_hierarchy | 15 | 第一焦点、层级、安全区、文字停留和阅读顺序明确 |
| motion_causality | 15 | 每拍一个主动作，辅助反馈有原因、延迟和收束 |
| continuity | 15 | 对象、布局、色彩、光源、时间、因果和段尾接口可机械对照 |
| h3_executability | 15 | 模式/角色/时长/画幅正确，原生 Prompt 和请求体完整 |
| typography_data | 10 | 可见文字逐字锁定；数据有单位、基线、时间尺度和结论 |
| audio_design | 5 | 环境、动作声、对白和非叙事音乐分层，无伪同步 |
| risk_control | 5 | 只针对高概率失败给最小约束，并提供回退方案 |

`ready` 需要总分至少 85，且没有硬否决项。分数由可观察字段支持，不能用“高级、丝滑、电影感”补分。

## 硬否决项

出现任一项，`quality.status` 必须是 `needs_revision`：

- 段时长不是 4–15 秒整数。
- 镜头或微时间拍有缺口、重叠、越界、零时长或未覆盖段尾。
- 核心数字、专名、引用、因果或可见文字被改写/翻译。
- 未生成证据原生、机制原生、领域原生三种脑内候选，或第一个联想未经淘汰直接进入分镜。
- `selected_moves` 只有动作 ID，没有说明当前镜头、对象、状态和作用。
- `router_move_ids` 不等于确定性路由输出，或 `move_adaptations` 无法重放出 `selected_moves`。
- 主信号强制动作、主程序 spine、辅助程序/配方最低动作贡献缺失，或识别出的信号没有驱动任何最终动作。
- 程序/配方没有阶段职责 binding，适用融合规则被漏写/多写，或五阶段没有恰好覆盖全部动作。
- 多个世界动作并存却没有显式决定持久世界与局部责任。
- 添加原稿没有支持的事实、产品功能、人物、关系、结论或对白。
- 同一时间拍出现两个高能主动作，或动作没有 owner/from/to/settle。
- `micro_motion_plan` 只挂 MM 编号，没有当前对象、变化范围、镜头和失败防护的实际 binding。
- `attention_reading_plan` 漏绑/重复镜头，首焦或焦点路径含糊，文字阅读窗口使用 `medium/high` 运动预算，或非末镜没有可观察的焦点交棒。
- 任一可见主动作镜头缺少 `MM03`，含文字事件的镜头缺少 `MM09/MM11`，或局部更新被错误声明为全屏清场。
- 主体跨镜无理由跳位、变色、变形、换光源或丢失关键部件。
- 高密度信息同时配大幅运镜，文字无足够稳定停留。
- 底部旁白字幕、逐字口播字幕或旁白全文被要求生成。
- H3 首尾帧角色与 reference 角色混用，或 T2VA 使用 `adaptive`。
- H3 Prompt 缺少模式要求的字段、镜号、切点或稳定落点。
- `quality.total` 低于 85 却标记 `ready`。

## 段内逐拍审查

### 0–1 秒

- 是否能确认画布世界、主对象和第一焦点。
- 钩子是否是对象/事实/动作，而不是无意义闪光和粒子。
- 首帧模式是否忠实继承参考图的主体、构图、颜色和空间关系。

### 建立拍

- 主体、单位、目标、机制或冲突是否在动作前建立。
- 线条和路径是否等节点存在后才出现。
- 文字首次进入时是否有清晰视觉角色。

### 主动作拍

- owner 是否唯一。
- `from_state -> action -> to_state` 是否可观察。
- 辅助元素是否由主动作触发，而不是同步自发运动。
- 相机动作是否有目标和叙事目的；图形缩放不冒充相机运动。
- 是否先建立注意或起势，再发生唯一主变化；依赖层是否晚一个可感知短拍响应。
- 变化覆盖范围是否与语义范围一致，局部更新没有洗掉整个画布。

### 解释/证据拍

- 数据是否从基线到差值再到结论。
- 机制是否从总览到局部，最后回装或回到结果。
- 文件/UI 是否保留来源和真实文字，不生成伪小字。

### 收束拍

- 主动作已经刹车，画面没有未解释的持续漂浮。
- 关键文字至少稳定 0.8 秒；复杂数据/文件建议 1.5–2 秒。
- `end_state.signature` 能直接成为下一段 `initial_state.signature`。
- 最后一帧是可接续状态，不是随机中间帧。
- 阅读停留是否从结果完全稳定后开始计算，而不是把进入动画时间算作阅读时间。
- 每镜是否只有一个首焦和一个可复述信息增量；`focus_path` 是否按真实观看对象排序，`exit_focus` 是否能被下一镜接住。

### 微运动绑定审查

- `MM03` 是否真正落到每镜 `from_state -> peak -> to_state -> settle`，而非只写“平滑进入”。
- `MM04` 是否只服务章节、年代、地点或视觉世界重置；普通切镜不得用中性场掩盖。
- `MM05` 是否锁定可测量的坐标、轮廓、尺度、轴线或光源；“保持一致”不算锚点定义。
- `MM06` 的 `local | regional | full_frame` 是否与实际遮罩、擦除、光扫和推拉范围一致。
- `MM07/MM08` 是否由真实深度关系或题材对象完成接力，而非给任意蒙版补一个故事。
- `MM09/MM10/MM12` 是否让容器、槽位和持久世界先稳定，只改变本拍的新信息。
- `MM11` 是否让相机和主体共同安静；持续呼吸、漂浮和粒子残留不算停稳。

## 跨段审查

每两段机械对照：

```text
previous.end_state.signature == next.initial_state.signature
previous.visible_entities == next.inherited_entities (+ explicit enter/exit deltas)
previous.palette_semantics == next.palette_semantics
previous.open_motion == none, unless next explicitly continues it
```

章节重置也要有桥：清场动作、黑/白场、对象遮罩、匹配形态、纸页、窗口或题材原生擦除。不能把“下一段重新生成”当作连续性。

长内容每 2–4 段回到一个时间/空间/对象/因果锚；这不是固定镜数，主体和论证连续时可延长。

## 生成后审查

### 画面

- 对每个镜头检查开场、中点、收束和切点前后帧。
- 检查主体完整、边缘稳定、位置/尺度/朝向/材质/光源一致。
- 检查标题、数据和 UI 无乱码、变形、遮挡、截断和底部字幕带。
- 检查转场结束后新状态稳定，不在切点持续溶解。

### 运动

- 播放 0.5× 与 1×：确认主动作启动、辅助延迟、峰值和制动。
- 检查相机与对象是否互相抵消或同时过度运动。
- 检查形态匹配是否保持同一几何锚，而不是随机变形。

### 声音

- 对白/旁白是否逐字一致，嘴型状态与 on/off-screen 责任正确。
- 动作声是否落在可观察碰撞、展开、落位或清场上。
- 音乐动态是否为画面留出文字和关键音效空间。
- 跨镜连续音是否没有无理由重启。

### 跨段

- 拼接前后 12 帧/0.5 秒检查共同锚。
- 检查 H3 随机生成是否使对象身份、字体、颜色或纹理漂移。
- 同一段重生成时，不把已通过的其他段整体推翻。

## 差量修订

失败只输出最小补丁：

```yaml
failure:
  time_range: ""
  observable_problem: ""
  violated_gate: ""
preserve:
  - 已通过的对象、构图、颜色、节奏和声音
patch:
  - 只改变导致失败的状态/动作/文字/引用绑定
acceptance:
  - 修订后可观察的通过条件
regeneration_scope:
  - segment_id 或 shot_id
```

优先修根因：身份漂移补对象锁；信息拥挤减并发焦点；文字乱码改用参考图/真实 UI；动作混乱拆成连续时间拍。不要只追加“更稳定、更高级、更流畅”。
