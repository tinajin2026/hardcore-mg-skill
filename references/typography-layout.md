# 排版与布局

## 文字五角色

1. **章节标题**：命名时间、地点或论证阶段；短、稳定、可回顾。
2. **语义印章**：2–4 个字的高能判断，只在逻辑断点短时出现。
3. **证据标签**：人物、机构、来源、日期、术语和部件；靠近对象。
4. **数据数字**：数字是主角，单位、基线和时间尺度紧邻。
5. **UI/文件原文**：作为真实证据，保留来源并裁到可读范围。

默认不生成底部旁白字幕，不把 spoken text 或 voiceover transcript 作为画面文字。画面文字必须能回答“删掉后损失什么视觉信息”。

## 层级

- 每屏一个一级焦点。
- 二级信息最多一组，三级标签仅服务定位。
- 大字不与大数字同屏争夺主位，除非二者是同一个结论。
- 证据原文进入时，装饰、背景词和辅助图形主动降对比。
- 英文大词可作低对比环境语义，不能替代主要中文判断。

## 数据排版

```text
对象/类别
→ 基线值 + 单位 + 时间
→ 差值/比例
→ 一句结论或状态
```

- 不裸放数字。
- 同屏比较必须同单位、同尺度、同时间窗。
- 数字递增结束后保留可读停顿。
- 来源数字和推导数字使用不同标签或注记。

## 证据排版

- 文件先全貌，后局部；局部保留页码、标题或来源锚。
- 人物卡包含姓名/功能角色与一个必要标签，不堆履历。
- 关系图中，标签沿节点对齐；不要让线穿过正文。
- 引用只保留与当前论点直接相关的短句，正文摘要另列。

## 16:9 网格

- 外安全区至少保留画面宽高的 4%。
- 主窗口可占宽 64–92%，依据证据可读性决定，不为边框留过多空间。
- 产品英雄位优先居中或三分线，不频繁跳位。
- 关系图使用稳定槽位：中心、左右对手、上游、下游、结果区。

## 9:16 网格

固定三段：

```text
顶部 12–18%：章节命题/来源状态
中央 62–72%：主对象、证据、图表或实拍
底部 10–16%：安全留白、少量数据/来源；不是旁白字幕槽
```

网页/表格必须裁关键列和行，不可把桌面截图整体塞入竖屏。长词需要换行或改短，不能通过随视口缩放字体解决。

## 跨画幅容器

把 9:16 素材放入 16:9 时：

- 中央素材固定宽高和底线。
- 边缘区只放上下文、数字或分类，不复制素材。
- 容器最好来自题材：手机、剧院、档案窗、设备屏幕。
- 不模糊放大同一素材填满两侧，除非用户明确要求且不影响信息。

## 可读停留

- 短标签：至少覆盖一次完整注意转移。
- 一组数据：先出现对象，再出现数值，最后停留。
- 文件：按阅读量决定停留；无法读完就裁短，不要加速。
- 高密度图：保持相机稳定，分步揭示。

## 反模式

- 所有文字都用同一粗体大字号。
- 视觉主标题只是旁白的逐字复制。
- 大量小字和伪代码充当“科技感”。
- 颜色、描边、阴影同时强调一个标签。
- 底部字幕、HUD、数据和产品操作争同一安全区。
