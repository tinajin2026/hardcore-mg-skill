# 实拍、档案、真实 UI 与 MG 接力

## 职责表

| 媒介 | 优先承担 | 不应承担 |
|---|---|---|
| 实拍 | 人物、动作、场所、产品材质、使用、规模 | 同时解释多个抽象关系 |
| 档案 | 历史事件、原始语境、时代质感 | 未经说明的现代因果 |
| 文件/报道 | 原话、条款、数字来源 | 缩小成不可读背景纹理 |
| 真实 UI | 产品行为和工作流 | 被低保真重画成假界面 |
| MG | 关系、比较、因果、流程、不可见机制、记忆锚 | 冒充原始证据 |
| Hybrid | 跟踪、测量、设备输出、局部解释 | 遮住实拍真正要证明的对象 |

## 接力状态机

### 概念 → 现场

```text
定义问题/区别 → 保留关键词或对象锚 → 短清场 → 真实演示 → 轻标签确认
```

适合产品短片。概念 MG 要短，只解决无法从现场直接看懂的部分。

### 现场 → 信息叠加

```text
先给干净场景 → 识别主体 → 跟踪锚出现 → 单组数据更新 → HUD 退场
```

跟踪框必须绑定真实物体或视线目标。数据不应填满四周；手、脸、产品轮廓和道路优先不遮。

### 档案/文件 → 证据页

```text
原件全貌 → 来源/日期 → 局部放大 → 关键句框选 → 回全貌或切结果
```

保留来源和上下文，不将截取句子伪装成独立事实。

### 产品 → 内部机制 → 产品

```text
真实外观 → 构图匹配 → MG 剖面/路径 → 状态解释 → 回装 → 使用结果
```

进入和离开 MG 时，主体位置、尺度和朝向尽量一致。

### 窗口 → 全屏图解 → 窗口

持久工作台内播放采访或现场；关系复杂时，现有窗口边界扩张成全屏图解，解释后缩回。不要用无关转场另开世界。

## 连续锚

每个接力至少保留一个，复杂切换建议两个：

- `object_anchor`：同一产品、人物、文件、地点。
- `motion_anchor`：同向推近、放大、扫描、开合、沿路径移动。
- `composition_anchor`：主体的屏幕位置和比例接近。
- `color_anchor`：实拍中的颜色转为 MG 语义色。
- `sound_anchor`：语句重音、击点、环境声或机械声跨切点。

声音锚必须在实际音轨中确认，不能从静帧推断。

## 素材处理

- 档案素材可降饱和、加轻颗粒或统一边框，但不得抹掉来源特征。
- 产品实拍保持完整轮廓与自然材质，不为“统一风格”重度染色。
- 网页/文件先裁关键区域，再放大；不要缩整页。
- 低分辨率竖屏素材固定尺寸、底线和容器，不拉伸。
- 同一来源类型使用统一标题、日期、来源和页码位置。

## 失败判断

- MG 重复了实拍已经清楚表达的行为。
- 实拍只是无关 B-roll，没有证明当前论点。
- HUD 没有跟踪目标，像漂浮贴纸。
- 证据被装饰框压到不可读。
- 切换前后没有对象、动作、构图、颜色或声音锚。
- 真实素材和解释性重建没有视觉区分。

## 完成检查

暂停切点前后，能用一句话说明“什么保持了连续，什么信息发生了变化”。做不到就先修接力，不要加更复杂转场。
