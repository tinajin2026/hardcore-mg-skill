# 八类 MG 状态语法

## 养料边界

本图谱只保留从大规模分镜研究中蒸馏出的状态顺序、图层责任、节奏预算和否决项。运行时不需要也不得检索原片题名、媒体 ID、案例编号、时间码或来源指纹。

八类语法不是八种固定风格。它们是认知任务的段落骨架，具体画面由当前稿件触发的信号、复合程序和原子动作共同生成。

## 节奏预算

- 4–7 秒：1–2 镜、3–5 微拍，主程序闭合，不超过一个辅助程序。
- 8–11 秒：2–3 镜、4–7 微拍，允许两个辅助责任但仍只有一个主动作链。
- 12–15 秒：3–5 镜、5–9 微拍，最多三个辅助程序，并保留 0.8–2.0 秒 landing。
- 高密度机制、关系和数据减少镜头、增加固定坐标内的微更新；高能包装才接近镜头上限。

## 八类路由

| 类别 | Pattern ID | 核心认知责任 | 作为辅助时的边界 |

| 角色IP与剧情叙事 | `XPC-CHARACTER-GOAL-REACTION` | 建立目标、动作、环境反馈、反应和后果 | 可组合风险或品牌母题，不能让包装夺走角色主线 |

| 活动包装与片头视觉 | `XPC-TITLE-HOOK-MOTIF-LOCKUP` | 以单一钩子和母题变奏形成标题记忆 | 只在 HOOK/章节/落版承担高能，不移植到解释主体 |

### 信息图表与数据解释 | `XPC-DATA-BASELINE-DELTA`

- 认知责任：建立基线、只改变一个变量、形成可核对结论。
- 15 秒状态骨架：0.0–2.0s 对象/单位与基线；2.0–6.0s 比较对象同尺度进入；6.0–10.5s 差值或趋势只动一个变量；10.5–13.0s 结论印章；13.0–15.0s 稳定读数并保留下一段锚。
- 图层责任：背景坐标层、基准层、比较层、数据标签层、结论层；高密度时相机固定。
- 组合边界：可作为产品/流程/比较程序的 payoff 数据层。
- 否决项：没有单位的数字、同时增长多组数据、结论刚出现就切走。

### 品牌叙事与企业传播 | `XPC-BRAND-MOTIF-PROOF-LOCKUP`

- 认知责任：用持久母题连接价值动作、事实证明和记忆落版。
- 15 秒状态骨架：0.0–2.0s 品牌母题或核心矛盾；2.0–5.0s 母题转为价值动作；5.0–10.0s 产品/现场/证据接力；10.0–13.0s 回收核心判断；13.0–15.0s 原创标识或品牌落版稳定。
- 图层责任：持久母题层、真实证据窗口、价值文字层、产品/人物层、落版层。
- 组合边界：可吸收产品、人物或证据，但不能替代证明。
- 否决项：只做氛围不证明价值、连续口号轰炸、未经授权复刻 Logo。

### 产品功能与UI演示 | `XPC-UI-ANCHOR-ACTION-RESULT`

- 认知责任：锁定产品入口，展示输入、状态变化和使用结果。
- 15 秒状态骨架：0.0–2.0s 锁定产品/UI 入口；2.0–5.0s 用户动作或输入；5.0–9.0s 界面状态增量变化；9.0–12.5s 输出/收益可见；12.5–15.0s 回到产品身份和下一功能入口。
- 图层责任：设备/窗口身份层、真实 UI 层、交互焦点层、结果层、品牌/下一步层。
- 组合边界：可组合机制剖面与数据结果，产品身份始终优先。
- 否决项：重画清晰真实 UI、整屏同时动、功能结果没有因果输入。

### 角色IP与剧情叙事 | `XPC-CHARACTER-GOAL-REACTION`

- 认知责任：建立目标、动作、环境反馈、反应和后果。
- 15 秒状态骨架：0.0–2.5s 角色、目标和空间关系；2.5–6.0s 单一动作启动；6.0–9.5s 环境/道具晚半拍反馈；9.5–12.5s 表情或姿态反应；12.5–15.0s 后果定格或动作钩子。
- 图层责任：场景层、角色身份层、目标道具层、动作反馈层、对白/标签层。
- 组合边界：可组合风险或品牌母题，不能让包装夺走角色主线。
- 否决项：角色无目标地漂浮、嘴型与对白无约束、同一镜头新增无来源角色。

### 科普知识与公共传播 | `XPC-EXPLAIN-OVERVIEW-MECHANISM-RETURN`

- 认知责任：从现象进入系统局部，解释机制并回装结论。
- 15 秒状态骨架：0.0–2.0s 问题/现象；2.0–4.5s 系统总览；4.5–9.5s 放大唯一局部并演示机制；9.5–12.5s 结果/风险；12.5–15.0s 回装全局并落下可记忆结论。
- 图层责任：现象层、系统总览层、局部机制层、路径/因果层、结论层。
- 组合边界：可组合因果、数据或风险，解释责任优先。
- 否决项：逐句配图、机制拆开后不回装、解释性重建伪装成真实史料。

### 字体图形与抽象实验 | `XPC-TYPE-SHAPE-SEMANTIC-HIT`

- 认知责任：让字形/几何的状态变化直接等于语义变化。
- 15 秒状态骨架：0.0–1.5s 几何/字体基元建立；1.5–5.0s 一次主形变；5.0–8.5s 形态匹配进入第二语义；8.5–12.0s 文字命中并可读；12.0–15.0s 图形回收为稳定标记。
- 图层责任：底色/网格层、几何基元层、字形层、遮罩层、最终标记层。
- 组合边界：只适合作为主命题或转场语法，不覆盖事实证据。
- 否决项：无语义变形、每秒换字体、故障/粒子/扫描并发。

### 三维与混合媒介 | `XPC-3D-HERO-MATERIAL-HANDOFF`

- 认知责任：锁定英雄对象和材质，以拆解或媒介接力证明功能。
- 15 秒状态骨架：0.0–2.5s 英雄对象与材质光源锁定；2.5–6.0s 绕行/剖分二选一；6.0–9.5s 部件或媒介匹配接力；9.5–12.5s 功能/场景结果；12.5–15.0s 回到英雄角度与材质状态。
- 图层责任：环境/反射层、英雄对象层、结构/部件层、混合媒介窗口、文字/落版层。
- 组合边界：可承载产品、机制和活动包装，必须回到对象身份。
- 否决项：镜头和对象同时大幅旋转、材质跨镜漂移、分解后不回到同一对象。

### 活动包装与片头视觉 | `XPC-TITLE-HOOK-MOTIF-LOCKUP`

- 认知责任：以单一钩子和母题变奏形成标题记忆。
- 15 秒状态骨架：0.0–1.5s 单一高能钩子；1.5–4.0s 主题母题建立；4.0–8.5s 2–3 次同语法变奏；8.5–12.0s 活动/节目文字命中；12.0–15.0s 日期、主题或片名稳定落版。
- 图层责任：背景能量层、主题母题层、素材窗口层、标题层、活动信息层。
- 组合边界：只在 HOOK/章节/落版承担高能，不移植到解释主体。
- 否决项：每个变奏换一套转场、落版不足一秒、标题与主体同时抢焦点。

## 组合规则

1. 每段只选择一个主 Pattern ID，它决定 opening 到 landing 的宏观状态顺序。
2. 次 Pattern ID 最多一个，只能增强局部图层或阶段，不能带入第二套主世界。
3. 具体的多维组合由 `method-trigger-lattice.yaml` 决定；Pattern ID 不替代语义信号和方法职责图。
4. 每个微拍只有一个主动作，辅助反馈延后启动并在下一信息进入前制动。
5. 文字、数据、证据、产品和角色谁承担核心判断，谁才是第一阅读；其他全部降级。
6. Prompt 写当前主体、坐标、状态和动作，不写 Pattern ID、程序 ID、样片身份或研究统计。
