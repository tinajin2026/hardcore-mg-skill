# 动效与转场状态机

## 状态优先

先写四项，再写动效形容词：

```yaml
initial_state: 观众在第一帧看到什么
primary_action: 唯一高能动作
readable_hold: 什么状态需要被读懂
end_state: 下一段继承什么
```

“高级、丝滑、科技、震撼”不构成可执行动作。

## 动效原语

| 原语 | 语义 | 适用 |
|---|---|---|
| reveal | 新对象/证据进入 | 标题、人物、文件、产品 |
| replace | 同槽位状态变化 | 年份、对象版本、卡片 |
| align | 建立可比较尺度 | 产品谱系、主体对比 |
| stack | 数量/层级增长 | 单位堆叠、材料、组织 |
| connect | 建立关系或流向 | 供应链、资金、因果 |
| propagate | 信号/能量沿路径传递 | 网络、电力、离子、流程 |
| isolate | 降低其他层突出一个对象 | 证据、故障、关键参数 |
| magnify | 从全貌到局部 | 文件、地图、晶圆、UI |
| decompose | 外观进入内部层 | 产品、设备、材料 |
| reassemble | 从机制回到对象/结果 | 产品解释收束 |
| count | 数字或单位递增 | 性能、规模、成本 |
| clear | 章节清场 | 年代、主体、逻辑层变化 |

每个时间拍只选一个主原语；辅助原语不应改变焦点。

## 三种解释节奏

### 机制

```text
总览 → 指定局部 → 分层/传播 → 关键状态停留 → 回装/结果
```

### 因果

```text
原因节点 → 路径 → 中间状态 → 结果 → 成本/后果回收
```

### 数据

```text
对象与单位 → 基线 → 差值/趋势 → 结论 → 稳定停留
```

## 转场选择

- **硬切**：证据类型或内容换了，但世界/槽位不变。
- **白场/黑场**：章节、时间或论证层真正重置。
- **圆形/对象遮罩**：下段与圆形对象、镜头或物体有语义连接。
- **窗口扩张/收缩**：实拍窗口与全屏图解往返。
- **领域化擦除**：赛车扫屏、胶片曝光、纸页翻动；只在题材支持时。
- **匹配切**：产品、人物、文件或地图的位置和形状跨媒介保持。

不要为同一片引入五套转场。定义：

```yaml
intra_world: hard_cut_or_slot_replace
chapter_reset: one_primary_reset
live_mg_handoff: one_matching_transition
```

## 速度与停留

- 高能动作可以短，信息停留不能短。
- 表格、文件和流程的阅读时长由信息量决定。
- 高密度段保持相机稳定；速度来自信息出现顺序，不来自镜头乱动。
- 低运动不代表失败。稳定构图内的状态更新常比大幅运动更清楚。

## 声音同步

只有实际听过音轨时才写具体同步：

- 语句重音触发数字落位或结论出现。
- 机械动作对应真实或设计音效。
- 章节清场允许短静音或环境声变化。
- 不要让每个 UI 元素都有提示音。

若只有静帧/联系表，输出 `sound_sync: unverified`，不要伪造节拍证据。

## 常见失败

- 同一秒内推镜、粒子、数字增长、故障和对象旋转并发。
- 章节没有变却频繁白闪。
- 线条先出现但节点还不存在。
- 对象分解后跳到新角度，破坏身份。
- 数字动画结束就切走，没有可读停留。
- 所有镜头都有持续漂浮，导致真正动作不再显眼。
