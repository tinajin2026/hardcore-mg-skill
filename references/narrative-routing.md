# 叙事与媒介路由

## 分段原则

每个段落只保留一个 `core_claim`。切段优先级：

1. 因果闭合后。
2. 年代、地点或主体变化时。
3. 从提出问题转入证据时。
4. 从事实层转入机制层时。
5. 从危机转恢复、从铺垫转结论时。
6. 已形成可以继承的稳定段尾时。

若目标模型固定 5/10/15 秒，把语义段进一步编译为执行单元；不得反过来用模型时长切碎句义。普通话时长仅作初估：慢速约 3.8–4.4 字/秒，正常约 4.5–5.2 字/秒，快速约 5.3–6.0 字/秒。数字、英文、停顿和专名必须另计。

## 叙事功能

| Function | 要完成的认知任务 | 常用证据 | MG 首选动作 |
|---|---|---|---|
| HOOK | 建立冲突或问题 | 强事实、对象、对比 | 单一强动作、语义印章 |
| ORIGIN | 交代起点 | 年份、地图、人物、旧物 | 时间/地点进入、初始节点 |
| CONTEXT | 建立背景 | 现场、制度、市场 | 世界和尺度定位 |
| EVIDENCE | 证明判断 | 文件、原话、数据、实拍 | 全貌→局部框选→来源 |
| COMPARISON | 统一尺度比较 | 产品、性能、成本、市场 | 基线→差值→结论 |
| PROCESS | 解释步骤 | 对象、材料、设备、路径 | 总览→局部→回装 |
| CAUSE | 解释为什么 | 节点、关系、流向 | 原因→传输→结果→回收 |
| CONFLICT | 呈现主体竞争 | 人物、企业、政策、路线 | 语义色分配、位置对抗 |
| CRISIS | 显示失效或压力 | 下跌、故障、阻断、账单 | 状态衰减、路径中断 |
| RECOVERY | 显示重启 | 新节点、产线、资金、产品 | 重新点亮、结构修复 |
| CONCLUSION | 回收论点 | 主对象、关键数字、未来状态 | 回装、缩回全局、定格 |

## 语义标签

每段选择 1–4 个，标签决定视觉责任而非装饰：

`TIME` `PLACE` `PERSON` `INSTITUTION` `POLICY` `DOCUMENT` `QUOTE` `DATA` `COMPARISON` `PROCESS` `SPEC` `CAUSE` `CONFLICT` `CRISIS` `RECOVERY` `ACQUISITION` `EXPANSION` `ECOSYSTEM` `LIMITATION` `MATERIAL` `CONCLUSION`。

若一段需要超过四个标签，先拆段或明确主次。

## 媒介选择决策树

```text
是否必须证明真实存在/发生？
├─ 是 → 有可用实拍/档案/文件/真实 UI？
│  ├─ 有 → 以真实素材为主，MG 只标注和组织
│  └─ 无 → 显式标记为解释性重建，不伪装成史料
└─ 否 → 是否解释关系/比较/机制/因果？
   ├─ 是 → MG 主导
   └─ 否 → 用最简单的标题、对象或实拍，不制造无意义动画
```

## 题材路由

### 企业史、人物史

- 世界：纸面年鉴、证据桌面、建筑门户。
- 组件：年份、人物卡、文件、地图、产品谱系、组织关系。
- 节奏：换页和年份断句；活动/产品实拍作为现实落点。

### 调查、案件、金融、争议

- 世界：暗色证据板或可追溯工作台。
- 组件：人物、机构、关系线、资金路径、文件、来源状态。
- 关系线必须区分 `confirmed | inferred | unknown`。

### 产品、汽车、设备

- 世界：产品舞台或技术观察台。
- 组件：英雄对象、参数、部件、模式、使用场景。
- 优先锁定对象，再更新属性；材质和使用由实拍承担。

### 工艺、工程、材料

- 世界：稳定技术画布。
- 组件：剖面、路径、材料层、失效、成本、时间。
- 一次只高亮一层或一步；解释结束必须回装或回结果。

### 年度盘点、市场分析

- 世界：数据工作台。
- 一级坐标用年份，二级用赛道/公司/产品，三级才放具体数值。
- 图表与现场交替，避免整片 PPT 化。

### 产品发布、赞助短片

- 世界：高对比产品包。
- 组件：2–4 字语义印章、产品集群、基准图。
- 每次高能文字后回到产品或证据；不可连续轰炸。

## 信息密度

- `low`：一个主体 + 一个标签；适合情绪、产品质感、章节呼吸。
- `medium`：一个主体 + 一组关系/参数；默认。
- `high`：图表、文件或多节点；必须稳定相机并分步揭示。

高密度段不通过加快镜头解决，而通过减少并发动作、增加停留、拆分状态解决。
